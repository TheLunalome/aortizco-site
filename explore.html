A quick guide

What the roles and lines mean

Host and virtual machine

A host is a physical computer that runs virtual machines. A virtual machine is a separate software-defined computer that can group a set of jobs.

Storage and backup

Storage is where files live; a backup is a separate copy intended for recovery. A storage line does not prove backup coverage.

Firewall and application

A firewall filters or routes traffic between networks. An application role describes what a service does—not every route its traffic takes.
